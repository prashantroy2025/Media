# NASA Image & Video Library Provider Review

- **Provider ID**: `nasa_library`
- **Supported Media**: High-definition video clips (MP4), Ultra high-resolution planetary & cosmic imagery (JPEG/PNG)
- **Authentication**: **Keyless** (Public REST API at `images-api.nasa.gov`)
- **Rate Limit**: 60 requests per minute
- **Cache Policy**: 48-hour response cache
